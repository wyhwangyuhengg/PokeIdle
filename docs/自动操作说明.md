# 遇敌自动操作说明

手机 → 设置 → 遇敌与捕捉 / 自动补货，里面每个开关到底怎么起作用，一份说清。

## 一、三种模式互斥，先认清

| 模式 | 它会做什么 |
|---|---|
| **自动操作** | 自动丢球（按你勾选的球种） |
| **佛系模式** | 遇敌 30 秒没处理就自动逃跑；**开启它会自动关掉自动操作**（反之亦然） |
| **捕捉条件表里的「暂停」** | 最强：遇到就停手等你手动丢球，既不自动抓也不自动逃，佛系倒计时也不会启动 |

## 二、每个设置项是什么意思

### 自动使用精灵球（按捕获率）
勾上的球才会被自动丢出。选哪种球由"这只好不好抓"和"你还剩什么球"决定：

- 球的基础捕获率：普通球 **35%**、高级球 **70%**、大师球 **必中**；
- 高级球额外 **+6%** 绝对捕获率，对稀有和神兽的提升最明显——**抓神兽推荐用高级球**；
- 一直抓不到时有个安慰奖励：同一只从第 10 球起，每多丢一球捕获率 **+10%**；
- 每次没抓到时宝可梦有概率挣脱逃跑：第 1 球 4%，每多丢一球 +4%，**最高 40%**；
- **只勾大师球也算一种正常配置**：这时候大师球就是你唯一允许用的球，任何遭遇都会用它（不会出现"有大师球却放跑"的情况）。

### 闪光 / 神兽使用大师球
- 勾上：遇到**闪光**和**神兽**优先用大师球；
- **重要副作用**：勾上之后大师球就"专供"了——普通宝可梦再也不会在前两种球用光时拿大师球兜底，避免大师球丢在路边怪身上。想恢复兜底就把勾去掉；
- 前提是**你还勾了普通球或高级球**。如果只勾了大师球，它没有别的球可让位，那就还是照常丢大师球；
- 神兽不受影响，**任何时候都优先大师球**。

### 外观特效使用大师球
时空扭曲事件里的 **RGB / 污染变体**同样优先大师球。勾上它之后，普通遭遇也不再拿大师球兜底（和上一条一样，同样以"你还勾了别的球"为前提）。

### 自动使用增益道具
- 甜甜蜜 / 闪耀护符：勾上的瞬间就用一瓶（如果当前没有别的增益在跑）；
- **骑行中不会用、也不会续**——骑车不遇敌，用了纯浪费；等你下车回到挂机自动补上；
- 两种增益互斥，同一时间只会生效一种。

### 捕捉条件表格（最核心的一块）

六行 = 六类遭遇：**特效（扭曲）／神兽／神兽闪／普通／普通闪／可悬赏**，每行可选三种策略：**捕捉 / 暂停 / 逃跑**。

- **判定优先级**：特效 > 神兽 > 神兽闪 > 普通 > 普通闪 > 可悬赏。
  - 时空扭曲事件里的所有遭遇都走「特效」行，其它规则一概不参与；
  - 「可悬赏」是兜底：普通行放行捕捉后，如果这只正好是**今日悬赏目标**，才轮到它做最终决定；
  - 神兽不看「可悬赏」行。
- **捕捉等级**（只对「捕捉」档有效）：写 0 就是不限制；等级超出范围的会自动逃跑。暂停/逃跑档不显示这一列，因为它们本来就不抓。
- **未拥有**（只对「捕捉」档有效）：仓库里已经有**同形态**的不再抓。注意是**分形态**算的——**闪光只跟闪光比**：你只抓过普通形态的话，它的闪光形态仍然会抓。

### 佛系模式
遇敌后 30 秒倒计时（底部有进度条），到点自动逃跑；**每丢一次球会重新计时**。判为「暂停」的遭遇不会跑。

### 自动补货

| 开关 | 行为 |
|---|---|
| 自动补球 | 勾选的球用光时花糖果补 1 个：普通球 10 / 高级球 25 / 大师球 2000。按你排的「补球优先级」（左高右低）补，只有勾选的球会被补 |
| 自动补增益道具 | 甜甜蜜 40 / 闪耀护符 20000。**只管把背包补上，用不用看上面的「自动使用增益道具」** |

## 三、常见问题

**Q：只勾了"只抓未捕捉"，又开了"闪光用大师球"，遇到已经抓过的精灵，但它这次是闪光形态，会怎样？**
A：**会抓，而且优先用大师球。**「未拥有」是分形态判定的——闪光只跟闪光比，你只抓过普通形态不算"有"。反过来说，如果这只的**闪光形态你也已经有过**了，那就直接放跑，一颗球都不会浪费（哪怕大师球开关开着）。

**Q：为什么开了"闪光/神兽使用大师球"后，普通宝可梦不扔大师球了？**
A：这是刻意的"专供"设计：大师球只留给闪光 / 神兽 / 特效变体，免得前两种球用光时把大师球丢在随手遇到的宝可梦身上。想恢复"大师球兜底"就取消勾选。

**Q：我只勾了"大师球"，遇到闪光会不会因为"大师球要留着给闪光"反而逃跑？**
A：不会。大师球"预留"的前提是**你还勾了别的球**（那样才有球可以让它让位）。只勾大师球时，它就是你唯一允许的球，遇到什么都会用它。
反过来说：**如果你希望"普通怪不要浪费大师球、前两种球用光就逃跑"**，正确做法是把普通球和高级球也勾上，同时开启「闪光/神兽使用大师球」——这样路边怪在前两种球耗尽后会自动逃跑，大师球只有闪光/神兽/变体才会动。

**Q：一只球都没有了会怎样？**
A：先按「自动补球」补（如果开了，且糖果够）；补不到就等 0.8 秒自动逃跑。这种"没球逃跑"不会计入欧气评定。

**Q：抓神兽到底用哪种球？**
A：神兽**无条件优先大师球**；没有大师球时推荐高级球——额外 +6% 绝对捕获率，对低捕获率的神兽增幅最明显。

**Q：时空扭曲（事件区）里的宝可梦按哪一行判？**
A：整片区域都按「特效」行处理（包括里面的神兽和闪光），其它行和等级、未拥有都不参与。

**Q：骑行时勾了"自动使用增益道具"怎么没反应？**
A：那是故意的——骑行不遇敌，增益用了是白烧；等你结束骑行回到挂机，会立刻给你续上。
